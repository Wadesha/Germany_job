🛠 操作方法

1. 生成简历（Node.js 脚本）

cd scripts
npm install          # 安装 docx 依赖（首次）
node generate_resume.js          # 生成德语简历
node generate_sample_resume.js   # 生成样例简历（含示例背景）

2. 更新职位市场数据

编辑 data/ 下的 jobs.csv 或 market_data_2026.*，重新跑采集脚本后同步更新 docs/data_reports/ 中的分析报告。

3. 走求职流程

步骤对应文档
规划docs/planning/job_hunt_plan.md
执行docs/planning/execution_handbook.md
投岗位docs/positions/ + resume/ + cover_letter/
查进度本地 private/求职进度跟踪.xlsx

4. 办签证

常规工作签证：docs/visa/work_visa_guide.txt ｜ 机会卡：opportunity_card_guide.txt ｜ 技能对标：skill_requirements.txt

🔒 隐私说明：private/ 目录存放含真实个人信息的文件（样例简历含 PwC / 阿里背景、求职进度跟踪表），已在 .gitignore 中排除，不会上传到 GitHub。仓库内仅保留模板与生成脚本，真实材料在本地维护。
