## 求职信结构说明 / Cover Letter Structure Guide

### 标准结构 / Standard Structure

| 部分 | 内容 | 字数建议 |
|------|------|----------|
| 开头段落 | 申请职位、公司名称、为何感兴趣 | 2-3句 |
| 第二段 | 核心技能和相关经验 | 4-5句 |
| 第三段 | 具体成就（量化数据） | 3-4句 |
| 第四段 | 为何选择该公司 | 2-3句 |
| 结尾 | 期待面试、感谢 | 1-2句 |

### 关键要素 / Key Elements

1. **量化成果**: 使用具体数字（10M+ events, 40% cost reduction）
2. **公司研究**: 提及公司的具体产品/服务/文化
3. **技能匹配**: 直接对应职位要求
4. **个人故事**: 将背景经历串联成有逻辑的职业路径
